# Estudos HTML 102

Repositório dedicado ao aprendizado dos fundamentos de desenvolvimento web utilizando HTML5 e CSS3. Durante as aulas foram abordados conceitos essenciais para a construção de páginas web estruturadas, semânticas e estilizadas de acordo com as boas práticas do mercado.

---

## 📚 Conteúdos Estudados

### Módulo 1 - Introdução ao HTML

- ✅ O que é HTML e sua importância no desenvolvimento web
- ✅ Estrutura básica de um documento HTML
- ✅ Declaração `<!DOCTYPE html>`
- ✅ Tags fundamentais:
  - `<html>`
  - `<head>`
  - `<body>`
- ✅ Criação do primeiro arquivo `.html`
- ✅ Execução e visualização da página no navegador

### Módulo 2 - Configurações da Página

- ✅ Uso de metatags
  - `<meta charset="UTF-8">`
  - `<meta name="viewport">`
- ✅ Configuração do título da página com `<title>`
- ✅ Vinculação de arquivos externos com `<link>`

### Módulo 3 - HTML Semântico

- ✅ Estruturação semântica de páginas
- ✅ Elementos:
  - `<header>`
  - `<nav>`
  - `<main>`
  - `<section>`
  - `<article>`
  - `<aside>`
  - `<footer>`

### Módulo 4 - Projeto Prático

- 🔄 Desenvolvimento de um layout de site de notícias/blog utilizando elementos semânticos.

### Módulo 5 - Introdução ao CSS

- ✅ Conceito de CSS (Cascading Style Sheets)
- ✅ Sintaxe CSS:
  - Seletor
  - Propriedade
  - Valor

Exemplo:

```css
h1 {
    color: blue;
}
```

### Módulo 6 - Seletores CSS

- ✅ Seletor Universal

```css
* {
    margin: 0;
    padding: 0;
}
```

- ✅ Seletor por Tipo

```css
p {
    color: black;
}
```

- ✅ Seletor por Classe

```css
.destaque {
    color: red;
}
```

- ✅ Seletor por ID

```css
#menu {
    background-color: gray;
}
```
